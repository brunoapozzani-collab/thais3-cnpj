# Mascot — Interactive Thais (Elsa) Character

Interactive Elsa-inspired mascot (My Talking Tom-style) that lives on the Projectos Taag web app. Half-screen mascot with touch/click interactions, half-screen actual app function.

## Before working, read:

- **WAT framework:** `../../templates/docs/wat-framework.md`
- **Sprite generation pipeline:** `workflows/sprite_generation.md`

## Character Reference

- Elsa from Frozen — ice queen princess, platinum blonde French braid, pale skin, blue eyes
- Ice-blue ball gown with snowflake crystalline cape, ice queen tiara
- Premium/polished 3D-illustrated style, cool blue cinematic lighting
- Personality: elegant, composed, witty — sophisticated humor with ice/winter metaphors

## Tech Stack

- **Asset generation:** LoRA (trained on Replicate) for consistent character poses
- **Frontend widget:** HTML5 video-based sprite engine (embeddable in any URL)
- **Assets:** Sprite sheets in `assets/sprites/`, videos in `assets/videos/`
